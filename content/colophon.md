This site is a digital garden, built and maintained with a small set of tools.

## Writing

Notes are written and organized in [Obsidian](https://obsidian.md), a local-first, Markdown-based note-taking app. It's where ideas start as loose fragments before they're ready to be published here.

## Building

The garden is generated with [Quartz](https://quartz.jzhao.xyz), a static-site generator built specifically for turning Markdown notes into a website — link graphs, backlinks, and all.

## Hosting

The site is hosted for free on [GitHub Pages](https://pages.github.com), served directly from the repository where the source lives.
